2. Qué datos se tratan y por qué

2.1 Datos de navegación (dirección IP)

Como cualquier servidor web, el servidor que aloja este sitio registra automáticamente la dirección IP del dispositivo del visitante con fines técnicos (gestión de la conexión). Estos datos no se utilizan para identificar personas ni se ceden a terceros, y se eliminan automáticamente según la política de retención de logs del proveedor de alojamiento (Vercel Inc.).

  • Base jurídica: Interés legítimo del responsable para garantizar el funcionamiento técnico del sitio (art. 6.1.f RGPD).
  • Conservación: El período que establezca el proveedor de alojamiento para sus registros técnicos.

2.2 Google Maps (carga bajo consentimiento)

Este sitio web incluye un mapa integrado de Google Maps. El mapa no se carga automáticamente: solo se activa si el usuario pulsa expresamente el botón «Activar mapa». En ese momento, la conexión con los servidores de Google (Google LLC, EE.UU.) implica la transmisión de la dirección IP del usuario a Google.

  • Base jurídica: Consentimiento del usuario (art. 6.1.a RGPD).
  • Tercero receptor: Google LLC. Puede consultar su política de privacidad en policies.google.com/privacy.
  • Google LLC está adherida al marco EU-U.S. Data Privacy Framework, que garantiza un nivel de protección adecuado para las transferencias internacionales de datos.

2.3 Fuentes tipográficas

Este sitio web utiliza fuentes tipográficas (Fraunces, Inter y Space Mono) que se sirven directamente desde el propio servidor de alojamiento, sin establecer ninguna conexión con servidores de Google Fonts u otros terceros.

2.4 Ausencia de cookies propias o de analítica

Este sitio web no utiliza cookies propias de sesión, rastreo o analítica. No se instala ninguna cookie en el dispositivo del usuario sin su consentimiento expreso. Únicamente se usa el almacenamiento local del navegador (localStorage) para recordar si el usuario ha activado voluntariamente el mapa de Google, con el fin de no volver a mostrarle el aviso en visitas posteriores. Este dato no abandona el dispositivo del usuario.
